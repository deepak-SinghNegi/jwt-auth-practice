# 🔐 MERN Authentication System

A full-stack authentication project built with **MongoDB, Express.js, React, and Node.js (MERN)** to practice modern authentication and authorization workflows.

The project includes a secure backend API and a React frontend that communicates with the server using HTTP requests and cookies.

## ✨ Features

### Backend
- User Registration
- User Login
- User Logout
- Password Hashing with bcrypt
- JWT Authentication
- HTTP-only Cookie Authentication
- MongoDB with Mongoose
- Environment Variables using dotenv
- RESTful API

### Frontend (React)
- User Registration Form
- User Login Form
- Protected Pages
- Authentication State Management
- API Integration using Axios
- Persistent Login
- Logout Functionality
- Responsive UI
